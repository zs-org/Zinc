Control Flow: if, while, for

Zinc supports standard control flow constructs, which are passed through to Zig.

if and else

if (condition) {
    // ...
} else if (other_condition) {
    // ...
} else {
    // ...
}

while Loops

var i: i32 = 0;
while (i < 10) : (i += 1) {
    // ...
}

for Loops

Used for iterating over arrays, slices, or ranges.

const items = [_]i32{ 1, 2, 3 };
for (items) |item| {
    // use item
}

Memory in Control Flow

You can use safe memory and call free() inside loops or conditionals. The Zinc runtime ensures that deallocation is idempotent and safe even if called multiple times or on null pointers.

while (running) {
    safe data = fetch()
    if (data.error) {
        free(data)
        continue
    }
    process(data)
    free(data)
}
