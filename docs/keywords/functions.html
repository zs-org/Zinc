Functions

Functions in Zinc are explicit about their parameters and return types.

Void Functions

Functions that don't return a value can either omit the return type or explicitly specify void.

fn say_hello() {
    // ...
}

fn log_error(msg: []const u8) void {
    // ...
}

Returnable Functions

Specify the return type after the parameter list.

fn add(a: i32, b: i32) i32 {
    return a + b;
}

Error Unions and !

If a function uses memory strategies that can fail (like def, local, safe, raw), FZC automatically wraps the return type in an error union (e.g., !void or !i32). This allows you to use the try keyword for error propagation.

fn create_data() !Data {
    def d: Data = Data.init()
    return d.*; // Value is copied out, 'd' is freed
}

Function Modifiers

You can use pub, export, and extern modifiers as described in the Visibility & FFI section.
