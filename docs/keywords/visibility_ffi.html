Visibility & FFI: pub, export, extern

Zinc provides keywords for managing visibility and interfacing with external code, mapping directly to Zig's semantics.

pub

Makes a declaration visible to other modules that import this file.

pub const PI = 3.14159;
pub fn add(a: i32, b: i32) i32 { return a + b; }

export

Makes a declaration available to the linker, using the C calling convention by default. Useful for creating libraries that other languages can use.

export fn my_c_api() void {
    // ...
}

extern

Used to declare symbols that are defined in an external object file or library.

extern fn printf(format: [*:0]const u8, ...) i32;

Semantic Mapping

These keywords are passed through to Zig unchanged. They do not affect Zinc's memory model but are essential for structuring programs and FFI.
