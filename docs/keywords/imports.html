Module System: import

Fundamental Zinc features a clean module system that maps directly to Zig's file-based imports while adding project-wide transpilation support.

Semantics

  • Only Zinc modules (.zn files) can be imported using the import keyword.
  • Imports are resolved relative to the current file.
  • The transpiler (FZC) automatically crawls all imports and transpiles the entire dependency tree.
  • Optional aliasing is supported with as.

Forms

import math
import graphics as gfx
import utils/logger

Transpiled Zig

const math = @import("math.zig");
const gfx = @import("graphics.zig");
const logger = @import("utils/logger.zig");

Project Structure

FZC preserves your directory structure. If you have a file at src/main.zn that imports src/lib/helper.zn, FZC will generate src/main.zig and src/lib/helper.zig.
