Keyword: raw

The raw keyword provides fully unsafe heap allocation. It bypasses Zinc's safety checks and is intended for expert usage, FFI, or low-level allocator implementation.

Semantics

  • Directly allocated via zinc_allocator.
  • No automatic cleanup.
  • No leak detection or escape analysis.
  • The developer is responsible for all lifetime management.

Example

raw ptr: *u8 = c.malloc(10)
// No safety checks performed on 'ptr'

Transpiled Zig

var ptr: ?*u8 = try zinc_allocator.create(u8);
// ...
