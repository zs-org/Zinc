Keyword: def

The def keyword represents safe heap allocation with block-scoped lifetime. It ensures that memory is automatically freed when the scope is exited.

Semantics

  • Allocated via the standard Zinc allocator.
  • Automatically freed at the end of the current block using defer.
  • Cannot escape the block where it was defined.
  • Manual free() is not allowed for def variables.

Example

{
    def data: Data = Data.init()
    data.process()
    // 'data' is automatically freed at this closing brace
}

Transpiled Zig

{
    var data = try _zinc_alloc(Data);
    defer _zinc_dealloc(&data);
    data.* = Data.init();
    data.process();
}
