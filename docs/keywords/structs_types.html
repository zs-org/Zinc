Structs & Types

Structs in Zinc are used to define custom types and can function similarly to classes by including methods.

Defining a Struct

pub const Vector2 = struct {
    x: f32,
    y: f32,

    pub fn init(x: f32, y: f32) @This() {
        return @This(){ x = x, y = y };
    }

    pub fn add(self: @This(), other: @This()) @This() {
        return @This(){
            x = self.x + other.x,
            y = self.y + other.y,
        };
    }
};

Using Struct Literals

In Zinc, you can write struct literals with a cleaner syntax (no leading dots). FZC automatically transpiles these to valid Zig syntax.

const v = Vector2{ x = 1.0, y = 2.0 };

Methods and @This()

The @This() builtin returns the type of the innermost struct, union, or enum. It is commonly used for constructors and self-references in methods.

Zinc Types vs. Classes

While Zinc doesn't have a formal class keyword, structs with methods provide the same functionality without hidden overhead. All memory behavior remains explicit through the five memory strategies.

def player: Player = Player.init("Jules")
player.move(10, 20)
// 'player' is automatically cleaned up at end of block
