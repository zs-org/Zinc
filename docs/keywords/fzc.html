The Fundamental Zinc Compiler (FZC)

FZC is a lightweight transpiler that converts Fundamental Zinc (.zn) files into standard Zig (.zig) files.

Usage

python3 fzc.py <entry_point.zn>

Core Features

  • Recursive Transpilation: Automatically finds and transpiles all imported modules.
  • Directory Preservation: Maintains the exact subdirectory structure of your source files.
  • Leak Detection: Performs static analysis to ensure safe variables are always freed or moved.
  • Error Union Insertion: Automatically updates function signatures to return error unions (!void or !T) if they use memory strategies that can fail.

Runtime Support

Every transpiled file automatically includes a reference to zincstd.zig, which provides the memory management primitives _zinc_alloc and _zinc_dealloc.

Cleanup Hook

If you are using the default GeneralPurposeAllocator, you should call zinc_deinit() at the end of your program (usually in main) to finalize the allocator and run leak detection.

pub fn main() {
    defer zinc_deinit();
    // ... your code ...
}
