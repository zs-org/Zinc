Keywords: fix and fixblock

The fix strategy allows for allocation within a fixed-size buffer on the stack. This is ideal for scenarios where heap usage is restricted or for deterministic performance.

Semantics

  • fix variables must reside inside a fixblock.
  • fixblock(size) creates a FixedBufferAllocator using a stack buffer of the specified size.
  • All fix allocations within the block use that buffer.
  • No heap memory is used.

Example

fixblock(2048) {
    fix buffer: [100]u8 = undefined
    fix header: Header = Header.init()

    // Use buffer and header...
}

Transpiled Zig

{
    var __fix_buffer_1: [2048]u8 = undefined;
    var __fix_allocator_1 = std.heap.FixedBufferAllocator.init(&__fix_buffer_1);

    const buffer = try __fix_allocator_1.allocator().create([100]u8);
    // ...
}
