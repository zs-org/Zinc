Zig Integration

Zinc is built to be 100% compatible with Zig. It provides two primary mechanisms for direct Zig integration.

1. Zig Escape Hatch

The zig { ... } block allows you to embed raw Zig code directly into your Zinc source. FZC will copy the contents of the block verbatim into the output Zig file.

zig {
    const std = @import("std");
    std.debug.print("Hello from raw Zig!\n", .{});
}

2. Keyword Forwarding

To use a Zig keyword that might conflict with Zinc or to ensure a keyword is passed through unchanged, use the @@ prefix.

const x: i32 @@addrspace(.generic) = 10;

FZC will remove the @@ prefix and pass addrspace through to the output.

Standard Library

All Zig builtin functions are supported unchanged in Zinc code:

  • @import
  • @sizeOf
  • @ptrCast
  • @panic
  • ...and all others.
