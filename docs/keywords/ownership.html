Ownership: move and borrow

Fundamental Zinc uses explicit ownership transfer and borrowing to manage heap lifetimes safely.

Move Semantics

The move keyword transfers ownership from one variable to another. The source variable is invalidated (set to null).

move x -> y

Zig Equivalent: var y = x; x = null;

Borrowing

The borrow keyword creates a reference without transferring ownership. The borrower has no responsibility for freeing the memory.

borrow x -> ref

Zig Equivalent: const ref = x;

Ownership Rules

  • Standard assignment (x = y) is not allowed for heap-managed variables.
  • Exactly one variable owns a heap allocation at any time.
  • Only the owner can call free() or let the allocation be automatically cleaned up (for def).

Example

safe a: Data = load()
move a -> b
// 'a' is now null, 'b' owns the Data
borrow b -> c
// 'c' can access the Data, but 'b' is still the owner
free(b)
