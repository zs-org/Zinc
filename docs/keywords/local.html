Keyword: local

The local keyword provides function-scoped arena allocation. It is the primary performance allocator in Fundamental Zinc.

Semantics

  • A function may have zero or more local variables.
  • On the first occurrence of local in a function, an ArenaAllocator is created.
  • All local allocations in that function use the same arena.
  • The arena is freed exactly once, at function exit.
  • Individual local variables are never freed manually.

Example

fn process_data() {
    local list: []i32 = init_list()
    local buffer: [1024]u8 = undefined

    // Use list and buffer...
    // Both are freed when process_data returns.
}

Transpiled Zig

fn process_data() !void {
    var __local_allocator_1 = std.heap.ArenaAllocator.init(zinc_allocator);
    defer __local_allocator_1.deinit();

    const list = try __local_allocator_1.allocator().create([]i32);
    // ...
}
