Keyword: safe

The safe keyword is used for long-lived heap allocations that require explicit ownership management. Unlike def, safe variables must be manually freed.

Semantics

  • Allocated via the standard Zinc allocator.
  • Must be freed manually using free(x).
  • FZC enforces that every safe variable is either freed or moved.
  • The runtime protects against double-frees by poisoning pointers.

Example

fn main() {
    safe config: Config = load_config()

    if (needs_update) {
        config.update()
    }

    free(config)
}

Transpiled Zig

var config: ?*Config = try _zinc_alloc(Config);
config.* = load_config();
// ...
_zinc_dealloc(&config);
